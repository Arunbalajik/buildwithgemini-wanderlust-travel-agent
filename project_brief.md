# My agent: Wanderlust - Travel & Exploration Concierge
One-liner: A conversational agent that helps travelers discover, plan, and budget customized trips with a catalog of destination itineraries, attractions, and local experiences.

Tool coverage:
- Memory: User travel preferences, dietary restrictions, preferred travel pace, past visited destinations, and budget tiers across sessions.
- Tools: Destination attraction lookup, flight/hotel estimate finder, day-by-day itinerary generator, weather/local timing queries.
- Catalog/UI: Itinerary cards, landmark comparison tables, hotel/activity recommendation cards rendered via A2UI.
- Image gen: Scenic destination concept cards, landmark previews, custom travel postcard illustrations.
- Sandbox: Trip budget optimizer, currency conversions, travel duration and expense breakdown calculations.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for trip budget/expense calculations, Google Maps integration, Cloud Trace observability
